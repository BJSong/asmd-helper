# AFSR Math 구현 워크플로우

## 1. 분석
빈 저장소에서 시작. 첨부의 기능 요구사항을 제품 사양으로 사용한다. 회원가입·AI·경쟁형 보상은 제외한다. 로컬 학습은 외부 계정 없이 동작해야 한다.

## 2. 설계
- 시각 방향: 따뜻한 종이색 배경, 짙은 초록색, 차분한 학습 노트의 인상.
- 콘텐츠: 오늘의 학습 중심 홈 → 계획 구성 → 한 문제 풀이 → 결과/복습 → 달력 기록.
- 상호작용: 버튼의 짧은 상태 변화와 진행 막대 전환만 사용. reduced-motion 지원.
- 순수 TypeScript 도메인 → Repository → Vue UI. 저장 후에만 다음 상태로 이동.
- 날짜는 Asia/Seoul, 타임스탬프는 UTC. 일일 과제 ID는 학습 날짜 기반.
- IndexedDB 트랜잭션으로 세션 생성/답안 병합. 일일 과제는 생성 당시 계획 스냅샷을 보존.
- 서버 API는 기본 비활성화 + 매 요청 서버 토큰 검증. 토큰은 환경 변수와 탭 메모리에서만 사용.

## 3. 구현
Nuxt 4 / Vue 3 / TypeScript / Tailwind 4 / Zod / IndexedDB. SQL 마이그레이션과 서버 API 제공.

## 4. 테스트
Vitest로 엔진 제약·채점·시간대·일일 분배·데이터 보존/복원을 검증. Playwright로 실제 학습과 새로고침, 모바일 화면, 클라우드 기본 차단 확인. 타입 검사 및 프로덕션 빌드.

## 5. 완성
실행 방법과 배포 준비, 검증 결과 및 제한을 README에 기록한다. 외부 계정 없이 실제 클라우드 연결·배포 완료를 주장하지 않는다.
